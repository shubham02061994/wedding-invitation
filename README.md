# Ranbir weds Alia — Indian Wedding Invitation

Mobile-first cinematic wedding invitation built with React + TypeScript + Vite + Tailwind CSS + Framer Motion + Lucide React.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

All wedding-specific copy, dates, functions, images, video ID, contact details and hashtag live in:

`src/data/weddingData.ts`

Replace `public/wedding-music.mp3` with a licensed audio file if you want the music button active. The RSVP form is intentionally front-end only; connect it to a backend/form service before production.
